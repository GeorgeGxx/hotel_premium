# Technical Debt & Remediation Register — `hotel_premium`

This register tracks every architectural, code, infrastructure, and security debt item discovered during the Phase 0 baseline audit and its remediation status.

| ID | Severity | Component | Description | Remediation Action | Target Phase |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **TD-01** | **P0 (Critical)** | `backend/internal/infrastructure/http/rbac.go` | `GinRBACMiddleware` trusts raw `X-User-Role` header unconditionally and grants `ADMIN` whenever `Authorization` contains substring `"admin"`. | Implement cryptographic JWT verification (HMAC/JWKS), remove substring bypass, support all 4 hotel staff roles + guest role, and gate `X-User-Role` header fallback behind verified gateway secret or dev/test mode. | Phase 1 & 4 |
| **TD-02** | **P0 (Critical)** | `infrastructure/kong/kong.yaml` & `compose.yaml` | Kong upstreams target `room-service`, `stay-service`, `billing-service`, `frontend` while Docker Compose names them `hotel-*` (or lacks network aliases), causing 502/503 errors. | Add network aliases (`room-service`, `stay-service`, `billing-service`, `notification-worker`, `frontend`) in `compose.yaml` AND align `kong.yaml` + `prometheus.yml` targets so both short and `hotel-*` DNS names resolve cleanly. | Phase 5 & 7 |
| **TD-03** | **P0 (Critical)** | `frontend/nginx.conf`, `frontend/Dockerfile`, `.env` | `nginx.conf` listens only on `5173` and hardcodes K8s DNS `10.96.0.10`; `.env` and `Dockerfile` set `VITE_API_BASE_URL=/api` instead of `/api/v1`, causing 404s and silent fallback to mock data. | Configure `nginx.conf` to listen on both `80` and `5173` without hardcoded K8s resolver in static SPA mode; set default `VITE_API_BASE_URL=/api/v1` across `.env`, `.env.example`, `compose.yaml`, and `Dockerfile`. | Phase 2 & 7 |
| **TD-04** | **P1 (High)** | `backend/internal/infrastructure/postgres/gorm_billing_repository.go` | `StayChargeModel.TotalPrice` attempts to `INSERT` into PostgreSQL `GENERATED ALWAYS` column `stay_charges.total_price`. | Add `gorm:"column:total_price;->;<-:false"` on `StayChargeModel.TotalPrice` and check all `tx.Exec` errors inside transactions. | Phase 1 & 3 |
| **TD-05** | **P1 (High)** | `backend/migrations/` | Missing SQL migration for `audit_logs` table used by `AuditRepository`. | Create `backend/migrations/000004_create_audit_logs.sql` with proper indexes on `entity_id`, `action`, and `created_at`. | Phase 1 & 3 |
| **TD-06** | **P1 (High)** | `backend/cmd/notification-worker/main.go` & `gorm_stay_repository.go` | Outbox writes `STAY_CREATED`, while `notification-worker` switches on `"StayCreated"`, so notifications never fire; `CheckOut` and `Cancel` omit outbox events. | Emit outbox events for `STAY_CREATED`, `GUEST_CHECKED_OUT`, and `STAY_CANCELLED` in `GormStayRepository`, and handle both canonical formats in `notification-worker` with Redis idempotency deduplication. | Phase 1 & 3 |
| **TD-07** | **P1 (High)** | `backend/cmd/room-service/main.go` & `billing-service/main.go` | `telemetry.InitBusinessMetrics()` is never called; `CacheManager` in `room-service` is unused; `billing-service` does not wire `redisClient` into `NewGinBillingEngine`. | Call `telemetry.InitBusinessMetrics()`, wire Redis `CacheManager` / idempotency middleware into services, and share underlying DB pool in `stay-service`. | Phase 1 & 3 |
| **TD-08** | **P1 (High)** | `k8s/helm/hotel-premium/` & `k8s/minikube/` | Image names omit `hotel-` prefix (`georgegxx/room-service:1.0.0` vs `georgegxx/hotel-room-service:1.0.0`); `hotel-postgres-init` ConfigMap is missing; `keda.yaml` attaches two `ScaledObject`s to `notification-worker` on wrong topics. | Standardize all images on `georgegxx/hotel-*:1.0.0`, define `hotel-postgres-init` ConfigMap, fix `keda.yaml` topics/targets, and upgrade Helm chart with `HPA`, `PDB`, `NetworkPolicy`, `ServiceAccount`, and `values-dev/staging/prod.yaml`. | Phase 7 |
| **TD-09** | **P1 (High)** | `devsecops/policies/gatekeeper/` | `security-constraints.yaml` passes `parameters.trusted_registries` instead of `parameters.registries` and duplicates `enforce-resource-limits`. | Fix constraint parameter schema to `parameters.registries`, remove duplicate constraint name, and align `conftest/kubernetes.rego` with OPA v1 syntax. | Phase 4 & 8 |
| **TD-10** | **P1 (High)** | `terraform/` | Missing AWS Terraform modules and environment configuration (`terraform/environments/aws/` and `terraform/modules/aws/`). | Implement modular AWS Terraform (VPC, EKS, RDS, ElastiCache, MSK, ECR, KMS, IAM/IRSA, OIDC, FinOps budgets) with strict security defaults. | Phase 7 |
| **TD-11** | **P1 (High)** | `.github/workflows/` & `devsecops/testing/` | `ci-devsecops.yml` uses `|| true` and `go-version: "1.23.x"`; `cd-aws.yml` is commented out; Postman and k6 tests are copy-pasted from `microservices-architecture` (`cosmo-router` / `/api/product`). | Remove all `|| true`, set `go-version: "1.26"`, add CycloneDX SBOM & Cosign digest verification, uncomment/complete `cd-aws.yml`, and rewrite Postman & k6 suites for `hotel_premium` endpoints. | Phase 8 |

| **TD-13** | **P2 (Medium)** | Workspace Hygiene | Untracked compiled binaries (`backend/api.exe`, `backend/bin/api.exe`), `devsecops/dast/zap/zap-report.html`, and unignored `backups/` / `__pycache__/`. | Delete stale binaries/reports and update `.gitignore` to exclude `backups/`, `__pycache__/`, and `*.tfstate*`. | Phase 1 |
